  Side Eye Series version: add  -p:Brand=SideEye  to the publish command. That uses
  Assets\SideEye.ico and builds Assets\SideEyeLogo.png into the app for the sidebar.
  Without it you get the generic version (Assets\VisualInventory.ico, pink badge).
  (The test makes its own throwaway Library inside the temp folder. The second path is
   the app's source, which the isolation check searches for forbidden code.)

IMPORTANT: package from the PUBLISH output (add -o <folder> to the publish command), never from
bin\Release\...\win-x64. The exe in bin is made by the ordinary build and does NOT contain the
"look only in Runtime" instruction, so it asks for .NET to be installed (the 3.0.0 mistake).

Package: copy the publish output (exe, dll, deps.json, runtimeconfig.json) into a project
folder, plus a Runtime folder made by extracting Microsoft's
dotnet-runtime-10.0.x-win-x64.zip and windowsdesktop-runtime-10.0.x-win-x64.zip into it.
The launcher only looks in that Runtime folder (AppHostDotNetSearch=AppRelative).

To update the runtime later: extract the newer two zips into Runtime and delete the
older version folders under Runtime\host\fxr and Runtime\shared\*.
